# Bolt 2 functional specification

Status: Implemented on 2026-08-18

- 108匹の重複しない出題候補を保持する。
- 発売済みの第1〜9世代の最初のパートナー27匹を必須候補とする。
- 小書きカタカナを大書きへ正規化する。
- かんたんは上下左右、ふつうは斜めを含む8方向へ配置する。
- 出題対象は盤面に一度だけ現れるまで埋め文字を再生成する。
- 全プリセットで異なる対象を指定数だけ配置する。
- 出題対象ではない候補名から、実在名と重ならない一文字違いのニアミス語を生成する。
- ニアミス語を小1個・中2個・大3個、難易度と同じ方向ルールで配置する。
