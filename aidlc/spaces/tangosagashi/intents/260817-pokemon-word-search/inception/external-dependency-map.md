# External dependency map

## Development dependencies

- npm registry: React, Vite, TypeScript, Vitest, Testing Library, Playwright
- GitHub: source repository and Actions
- GitHub Pages: static hosting

## Runtime dependencies

- None outside browser-standard APIs and the statically deployed application files
- No API, database, login provider, analytics, ad network, or external media host

## Human dependencies

- Product owner supplies or authorizes the GitHub repository destination.
- Product owner performs final iPhone and iPad smoke tests.
