# 出題候補の選定記録

## 現在の一覧

実装上の正本は [`src/data/pokemonCatalog.ts`](../src/data/pokemonCatalog.ts) です。重複を除く111匹を収録しています。

- 必須枠30匹: 本編第1〜10世代の「最初のパートナー」各3匹
- 選定枠81匹: 家族が名前を認識しやすいポケモンを、世代と名前の長さが偏りすぎないように選定

## 選定ルール

1. 歴代の最初のパートナーはすべて含める。
2. 公式のカタカナ表記を使用する。
3. 数字、記号、フォルム名を含む名前はMVPから除外する。
4. 8×8でも出題できる長さに収める。
5. 小書き文字は盤面上で大書き文字へ正規化するが、候補一覧には正式表記を保持する。
6. 公式人気投票の厳密な順位表とはせず、家庭での認知度と世代バランスを優先する。

## 確認元

- [ポケモンずかん](https://zukan.pokemon.co.jp/)
- [『ポケットモンスター ウインド・ウェーブ』最初のパートナー](https://www.pokemon.co.jp/ex/winds_waves/ja/pokemon/)

追加・削除時には、重複、正規化後の長さ、歴代の最初のパートナーが揃っていることを単体テストで検証します。
